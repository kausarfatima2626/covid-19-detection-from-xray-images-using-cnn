# COVID-19 & Pneumonia Detection from Chest X-Rays using CNN

**PulmoAI** is an end-to-end Deep Learning web application designed to analyze chest X-ray images and provide real-time classification across three categories: **COVID-19**, **Pneumonia**, and **Normal**.

## 📌 Features
- **Deep Learning Model:** Built using Convolutional Neural Networks (CNN) for high-accuracy feature extraction.
- **Web Interface:** Interactive and lightweight UI for instant image upload and prediction.
- **Multi-Class Detection:** Detects Normal lungs, Bacterial/Viral Pneumonia, and COVID-19 opacities.

## 🛠️ Tech Stack
- **Language:** Python
- **Frameworks:** TensorFlow / Keras, Flask / Streamlit
- **Frontend:** HTML5, CSS3
